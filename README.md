# 木谱 · Wood Atlas

为原创角色写手与画手准备的木材速查站。收录 43 种常见、名贵或有「戏」的木材，每种给出色泽、硬度、密度、纹理、气味、用途、相似木材、创作提示与常见误用。

纯静态页面：无框架、无构建、无外部字体与图片依赖。

## 运行

直接双击 `index.html` 即可，或起一个本地静态服务：

```bash
python3 -m http.server 8765
# 打开 http://127.0.0.1:8765
```

部署到 GitHub Pages / Netlify / Vercel 时，把整个目录上传即可，无需构建。

## 目录

```
index.html        页面结构
styles.css        视觉与打印样式
app.js            筛选、搜索、抽屉、纹理生成
data/woods.js     木材数据（唯一的日常编辑入口）
assets/wood/      可选：实拍刨面图
```

## 功能

- **搜索**：中文名、英文名、学名、别名、用途、产地、色系、创作提示全文匹配；按 `/` 聚焦，`Esc` 清空。
- **筛选**：色系、硬度、密度、产地、用途、价格，可多选组合。
- **详情抽屉**：刨面图、关键数据、三档色泽（新切心材 / 边材 / 氧化后）、材性、用途、创作提示、常见误用、冷知识、相似木材。
- **色值复制**：点击详情里的色块复制 hex，方便画手取色。
- **随机灵感**：顶栏「随机灵感」随机翻开一种木材。
- **打印设定卡**：详情页底部「打印设定卡」，按 A5 纵向输出，可直接贴进设定集。
- **深链接**：每张卡片都有 `#wood-id`，可以直接分享给同好。

## 编辑数据

所有内容在 `data/woods.js`。新增一种木材，复制一条并改字段即可，页面会自动统计数量、生成筛选项与色带。

```js
{
  id: 'white-oak',            // 唯一，用作 URL 锚点
  name: '白橡木',
  en: 'White Oak',
  sci: 'Quercus alba',
  aliases: ['白栎', '橡木'],
  type: '硬木',                // 硬木 / 软木 / 改性材 / 非木材
  origin: ['北美'],            // 北美 南美 欧洲 非洲 东南亚 南亚 中国 中美洲
  color: {
    heart: '#B0895C',          // 新切心材
    sap: '#DEC9A4',            // 边材
    aged: '#9E7549',           // 氧化后
    note: '心材浅黄褐至灰褐，久置转暖褐；边材近白。'
    // 非树种材料可自定义三档标签：
    // labels: ['稳定后', '基材本色', '长期使用'],
    // subs: ['树脂浸渗', '未处理', '可能变深']
  },
  janka: 6050,                 // 詹卡硬度 N；没有公认值时填 null
  density: 0.78,               // 气干密度 g/cm³
  feel: '硬',                  // 软 / 中 / 硬 / 很硬（janka 为 null 时用于筛选）
  grain: '直纹至山形纹，导管粗深，射线发达',
  texture: '中等粗糙，手摸有细密凹槽',
  work: '刨削需锋刃，含单宁遇铁会发黑；蒸汽弯曲性好。',
  smell: '生木微酸，成品几乎无味。',
  durability: '极耐腐，导管内有侵填体，防水性好。',
  uses: ['家具', '地板', '船舶', '建筑'],
  price: 2,                    // 1–4，对应 ¥ 到 ¥¥¥¥
  cites: false,                // 是否 CITES 附录 II
  // protection: '国家二级保护',   // 可覆盖保护级别显示
  // protectionSub: '禁止采伐与交易',
  similar: ['red-oak'],        // 必须是已存在的 id
  creative: '酒馆、酒窖、船坞场景的默认木材……',
  mistake: '白橡与红橡常被混卖……',
  fact: '白橡导管内的侵填体是天然防水层……',
  tex: { pattern: 'cathedral', contrast: 0.55, pores: true, rays: true, knots: 0 }
}
```

### 纹理参数

刨面图由 `app.js` 按 `tex` 参数程序生成（SVG），不使用位图：

- `pattern`：`straight` 直纹 / `cathedral` 山形纹 / `wavy` 波浪纹 / `interlocked` 交错纹 / `striped` 深浅条纹 / `birdseye` 鸟眼 / `burl` 瘤疤 / `fibrous` 纤维材
- `contrast`：0–1，纹理对比强度
- `pores`：导管孔（橡木、白蜡、胡桃等环孔材）
- `rays`：射线斑（橡木、榉木）
- `eyes`：鸟眼（枫木）
- `knots`：节疤数量

同一 `id` 生成的纹理是稳定的，刷新不会变。

## 换成实拍图

在 `data/woods.js` 的条目里加两个字段，页面会自动改用照片（卡片、详情、打印卡同步）：

```js
photo: 'assets/wood/white-oak.jpg',
photoCredit: 'Wikimedia Commons / CC BY-SA 4.0'
```

建议 3:2 或 2:1 裁切、长边 1200px 左右。使用时请确认授权并在 `photoCredit` 里署名。没有 `photo` 字段时继续用程序纹理，并在图上标注「示意」。

## 关于数据

- 硬度为詹卡硬度（Janka）参考值，密度为气干密度；两者随产地、含水率、生长条件显著浮动。

其中两条不是常规树种，已在数据里单独标注：

- **稳定木瘤**：树脂浸渗的改性材，`type` 为「改性材」，三档颜色用 `color.labels` 改成「稳定后 / 基材本色 / 长期使用」。
- **桫椤**：树蕨，不是真正的木材，`type` 为「非木材」，并用 `protection` 标注国家二级保护、禁止采伐交易。
- 小叶紫檀、黄花梨、交趾黄檀等没有可靠统一詹卡值的条目填 `null`，页面按「密度 + 手感」标注，并注明依据。
- 刨面图为程序生成的示意图，颜色与纹理方向对应真实特征，但不能替代实物照片。
- 内容用于创作参考，不作为采购、鉴定或工程依据。
